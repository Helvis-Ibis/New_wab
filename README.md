# Wabajob

Wabajob est une plateforme de recherche d'emploi et de recrutement conçue pour connecter les chercheurs d'emploi et les recruteurs en Afrique.

## Documentation

Pour une documentation complète du projet, veuillez consulter le fichier [DOCUMENTATION.md](DOCUMENTATION.md).

## Fonctionnalités

- **Pour les chercheurs d'emploi** : Recherche d'emploi, création de CV, gestion des candidatures, suivi des publications
- **Pour les recruteurs** : Publication d'offres d'emploi, recherche de profils, gestion des demandes de recrutement
- **Général** : Authentification, messagerie, notifications, formations

## Technologies utilisées

- React.js
- Tailwind CSS
- Vite
- React Router
- Lucide React (icônes)

## Installation

```bash
# Cloner le dépôt
git clone git@github.com:Samed6/wabajob.git
cd wabajob

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev
```

## Déploiement

Le projet est configuré pour être déployé sur Vercel.

```bash
# Déployer en prévisualisation
vercel

# Déployer en production
vercel --prod
```

## Structure du projet

- `/src` - Code source principal
  - `/components` - Composants réutilisables
  - `/pages` - Pages de l'application
  - `/assets` - Ressources statiques
